我正在处理知愈微信小程序的并行优化项目 - 分支3：知识库页面优化。

# 项目背景

知愈是一个情绪健康微信小程序，采用 Morandi 色系和玻璃态设计风格。当前正在进行4个分支的并行优化，我负责知识库页面（Knowledge 和 Psych-Knowledge）的优化工作。

# 我的任务范围

**只能修改以下文件**：
- `pages/knowledge/knowledge.js`
- `pages/knowledge/knowledge.wxml`
- `pages/knowledge/knowledge.wxss`
- `pages/knowledge/knowledge.json`
- `pages/psych-knowledge/psych-knowledge.js`
- `pages/psych-knowledge/psych-knowledge.wxml`
- `pages/psych-knowledge/psych-knowledge.wxss`

- `data/` 目录下的知识库数据文件（如果有）

**不能修改**：其他页面文件（由其他分支负责）

# 核心任务

1. **优化知识库内容展示** - 重新设计卡片样式（玻璃态），优化布局
2. **改进搜索和筛选功能** - 优化搜索框、分类筛选UI、添加搜索建议
3. **统一卡片设计** - 确保 knowledge 和 psych-knowledge 页面风格一致
4. **提升阅读体验** - 优化排版、字体、间距、添加阅读进度
5. **性能优化** - 虚拟滚动、图片懒加载、搜索性能（60fps）

# 设计规范

- **色系**: Morandi 色系（粉#F5C6CB、米驼#D4B8A5、薰衣草#C4B5D8、鼠尾草绿#C4D4B5、金#E8D4B8）
- **背景**: #FAF9F7
- **卡片样式**:
  - 玻璃态效果: `background: rgba(255,255,255,0.7)` + `backdrop-filter: blur(20rpx)`
  - 圆角: 16rpx
  - 阴影: `0 4rpx 12rpx rgba(0,0,0,0.08)`
  - 间距: 24rpx
- **封面图片**: 高度 320rpx，圆角 16rpx
- **动画**: `transition: all 0.3s ease`

# 核心功能要求

**必须保留的功能**：
- 知识文章列表展示
- 搜索功能
- 分类筛选
- 文章详情查看
- 收藏功能（如果有）

**优化方向**：
- 卡片采用玻璃态设计，添加封面图片
- 搜索框放在顶部固定位置
- 筛选标签使用横向滚动
- 阅读体验：字体 28-32rpx，行高 1.6-1.8
- 长列表使用虚拟滚动（>20条）

# 统一设计要求

**knowledge 和 psych-knowledge 必须统一**：
- 卡片尺寸、间距、圆角
- 色系应用

# 性能要求
