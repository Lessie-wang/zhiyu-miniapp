我正在处理知愈微信小程序的并行优化项目 - 分支2：AI对话页面修复。

# 项目背景

知愈是一个情绪健康微信小程序，采用 Morandi 色系和玻璃态设计风格。当前正在进行4个分支的并行优化，我负责 Chat（AI对话）页面的重新设计和优化工作。

# 我的任务范围

**只能修改以下文件**：
- `pages/chat/chat.js`
- `pages/chat/chat.wxml`
- `pages/chat/chat.wxss`
- `pages/chat/chat.json`
- `pages/chat/chat-redesign.wxss`（如果存在）

**不能修改**：其他页面文件（由其他分支负责）

# 核心任务

1. **重新设计对话界面UI** - 保留功能（小知头像、介绍、历史记录、保存按钮），改进呈现方式
2. **优化小知头像和介绍** - 重新设计展示区域，添加个性化元素
3. **改进历史记录交互** - 实现侧边栏滑入效果，优化卡片设计
4. **优化保存功能** - 改进按钮位置和样式，添加反馈动画
5. **提升对话流畅度** - 优化消息加载、滚动、性能（60fps）

# 设计规范

- **色系**: Morandi 色系（粉#F5C6CB、米驼#D4B8A5、薰衣草#C4B5D8、鼠尾草绿#C4D4B5、金#E8D4B8）
- **背景**: #FAF9F7
- **对话气泡**:
  - 用户消息：粉色渐变 `linear-gradient(135deg, #F5C6CB, #FFE0E5)`
  - AI消息：白色玻璃态 `rgba(255,255,255,0.7)` + `backdrop-filter: blur(20rpx)`
- **圆角**: 16rpx
- **阴影**: `0 4rpx 12rpx rgba(0,0,0,0.08)`
- **动画**: `transition: all 0.3s ease`

# 核心功能要求

**必须保留的功能**：
- 小知头像展示
- 小知介绍文案
- 实时对话（用户消息 + AI回复）
- 历史记录查看和切换
- 保存对话按钮

**优化方向**：
- 对话气泡采用玻璃态设计
- 历史记录使用侧边栏滑入效果
- 保存按钮移到顶部导航栏
- 添加"正在输入"指示器（三个跳动的点）
- 新消息自动滚动到底部

# 性能要求

- 保持 60fps 流畅度
- 优化消息列表渲染
- 减少不必要的 setData 调用
- 长对话（>50条消息）性能优化
- 使用 CSS transform 实现动画
