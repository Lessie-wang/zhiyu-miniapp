## 🎯 设计目标

根据用户反馈，完全重新设计 Index 欢迎页面：

1. **背景优化** - 使用 AI 生成的 Morandi 风格背景图，替代纯色背景
2. **蜡封改为邮戳** - 圆形蜡封改为信封邮戳样式，更符合信封主题
3. **简化交互流程** - 信封打开后直接向上滑动进入 main 页面，无需点击按钮
4. **添加滑动提示** - 半透明的手指向上滑动动画，引导用户操作

---

## 🎨 主要改动

### 1. **AI 生成背景图**

**生成参数**：
- **风格**：Morandi 色系，温柔治愈，水彩质感
- **元素**：抽象的情绪流动感，柔和的色彩晕染
- **色调**：米驼色 #D4B8A5、金色 #E8D4B8、粉色 #F5C6CB 的渐变融合
- **尺寸**：竖屏 9:16（1024x1792）
- **质量**：2K 高清

**实现效果**：
- 背景图作为底层，使用 `mode="aspectFill"` 填充整个屏幕
- 添加玻璃态遮罩层（`backdrop-filter: blur(20rpx)`）
- 背景与前景内容完美融合，营造温暖治愈氛围

### 2. **蜡封改为邮戳**

**设计变化**：

| 元素 | 原设计（蜡封） | 新设计（邮戳） |
|------|--------------|--------------|
| 形状 | 立体圆形蜡封 | 扁平圆形邮戳 |
| 位置 | 右上角悬浮 | 信封右上角贴合 |
| 颜色 | 金色发光效果 | 米驼色 #D4B8A5 线条 |
| 装饰 | 内外圈光晕 | 放射状线条（6条） |
| 动画 | 旋转消失 | 撕裂旋转消失 |

**邮戳结构**：
```
- 外圈：6rpx 边框圆形
- 文字："知愈" + 日期（如 "05-03"）
- 装饰：6条放射状线条（0°, 30°, 60°, 90°, 120°, 150°）
- 背景：半透明白色 rgba(255, 255, 255, 0.1)
```

### 3. **简化交互流程**

**原流程**：
1. 向上滑动撕开信封
2. 信封打开，显示信纸内容
3. 点击"开始书写今天的心情"按钮
4. 进入 main 页面

**新流程**：
1. 向上滑动撕开信封
2. 信封打开，显示信纸内容
3. **继续向上滑动信纸**
4. 直接进入 main 页面

**优势**：
- 减少一次点击操作
- 交互更流畅自然
- 符合"滑动翻页"的直觉

### 4. **添加滑动提示动画**

**两个提示阶段**：

**阶段1：信封未打开**
- 位置：信封下方
- 内容：向上箭头 + "向上撕开信封"
- 动画：上下弹跳（`bounce-up`）
- 颜色：灰色半透明

**阶段2：信封已打开**
- 位置：信纸底部
- 内容：手指图标 + 向上箭头 + "向上滑动开始"
- 动画：
  - 手指向上滑动（`hand-swipe`）
  - 整体脉冲闪烁（`hint-pulse`）
- 颜色：粉色半透明 #F5C6CB
- 延迟：信封打开后 0.8s 淡入

## 🔧 技术实现

### 1. **背景图加载优化**
```xml
<image class="bg-image" 
       src="/assets/images/index/welcome-bg.png" 
       mode="aspectFill">
</image>
```
- 使用 `mode="aspectFill"` 保持比例填充
- 图片尺寸 9:16 匹配竖屏设备

### 2. **玻璃态效果**
```css
.glass-overlay {
  background: rgba(250, 249, 247, 0.3);
  backdrop-filter: blur(20rpx);
  -webkit-backdrop-filter: blur(20rpx);
}
```
- 兼容 iOS 和 Android
- 模糊半径 20rpx 适中

### 3. **邮戳放射线**
```css
.postmark-lines .line:nth-child(1) { transform: rotate(0deg); }
.postmark-lines .line:nth-child(2) { transform: rotate(30deg); }
/* ... */
```
- 6条线均匀分布（每隔 30°）
- 使用 `transform-origin: center` 确保旋转中心

### 4. **滑动检测优化**
```javascript
// 信封已打开，向上滑动超过 80px 即跳转
else if (this.data.envelopeOpened && deltaY > 80) {
  this.goToMain();
}
```
- 阈值 80px 适中，避免误触
- 添加 `isNavigating` 标志防止重复跳转
