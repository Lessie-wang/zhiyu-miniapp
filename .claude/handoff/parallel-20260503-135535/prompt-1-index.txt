我正在处理知愈微信小程序的并行优化项目 - 分支1：Index 页面修缮。

# 项目背景

知愈是一个情绪健康微信小程序，采用 Morandi 色系和玻璃态设计风格。当前正在进行4个分支的并行优化，我负责 Index 欢迎页面的优化工作。

# 我的任务范围

**只能修改以下文件**：
- `pages/index/index.js`
- `pages/index/index.wxml`
- `pages/index/index.wxss`
- `pages/index/index.json`

**不能修改**：其他页面文件（由其他分支负责）

# 核心任务

1. **优化欢迎页面布局** - 重新设计布局，提升视觉吸引力
2. **统一 Morandi 色系** - 应用 #F5C6CB, #D4B8A5, #C4B5D8, #C4D4B5, #E8D4B8
3. **添加流畅动画** - 页面进入、按钮点击、导航过渡动画（60fps）
4. **修复导航逻辑** - 确保首次进入和再次进入的逻辑正确
5. **性能优化** - 图片懒加载、减少 setData、优化动画性能

# 设计规范

- **色系**: Morandi 色系（粉#F5C6CB、米驼#D4B8A5、薰衣草#C4B5D8、鼠尾草绿#C4D4B5、金#E8D4B8）
- **背景**: #FAF9F7
- **圆角**: 16rpx
- **阴影**: `0 4rpx 12rpx rgba(0,0,0,0.08)`
- **动画**: `transition: all 0.3s ease`
- **玻璃态**: `backdrop-filter: blur(20rpx)` + 半透明背景

# 性能要求

- 保持 60fps 流畅度
- 使用 CSS transform 实现动画（不用 left/top）
- 避免在动画中使用 setData
- 图片使用懒加载
