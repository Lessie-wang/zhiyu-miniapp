## 二、技术框架选择

**选择框架：UI优化型 + 功能增强型**

```
分析现状 → 设计方案 → 背景升级 → 图标优化 → 功能完善 → 测试验证 → 交付
```

### 设计原则
1. **视觉层次**：玻璃拟态 + 渐变 + 柔和阴影
2. **色彩系统**：延续品牌色（#F5C6CB粉、#D4B8A5米棕、#FAF9F7米白）
3. **动画反馈**：流畅微动效，提升交互体验
4. **响应式**：适配不同屏幕尺寸

### 背景设计方案

**方案A：渐变纹理背景**（推荐）
- 优点：轻量、性能好、符合品牌调性
- 实现：CSS渐变 + 伪元素纹理
- 复杂度：低
- 性能：优秀

**方案B：AI生成背景图**
- 优点：独特性强、视觉冲击力
- 缺点：文件大、加载慢
- 复杂度：中
- 性能：一般

**方案C：SVG动态背景**
- 优点：矢量、可交互
- 缺点：实现复杂
- 复杂度：高
- 性能：中等

**最终选择：方案A（渐变纹理）+ 局部SVG装饰**

## 三、具体实施计划

### 3.1 背景视觉升级

#### Chat页面（真心小筑）
```css
/* 多层渐变 + 点状纹理 */
background: 
  radial-gradient(circle at 20% 30%, rgba(245, 198, 203, 0.15) 0%, transparent 50%),
  radial-gradient(circle at 80% 70%, rgba(212, 184, 165, 0.12) 0%, transparent 50%),
  linear-gradient(180deg, #FFE8E0 0%, #FAF9F7 100%);
```

#### Companion页面（陪伴者）
```css
/* 温暖渐变 + 心形装饰 */
background: 
  radial-gradient(circle at 50% 20%, rgba(245, 198, 203, 0.2) 0%, transparent 40%),
  linear-gradient(180deg, #FFF0F0 0%, #FAF9F7 100%);
```

#### Dialogue Training页面（表达训练）
```css
/* 游戏化渐变 + 星光效果 */
background: 
  radial-gradient(circle at 30% 40%, rgba(196, 212, 181, 0.15) 0%, transparent 50%),
  radial-gradient(circle at 70% 60%, rgba(196, 181, 216, 0.12) 0%, transparent 50%),
  linear-gradient(180deg, #FFE8E0 0%, #FAF9F7 100%);
```

#### Emotion Library页面（情绪库）
```css
/* 知识感渐变 + 书页纹理 */
background: 
  repeating-linear-gradient(90deg, transparent, transparent 100rpx, rgba(212, 184, 165, 0.03) 100rpx, rgba(212, 184, 165, 0.03) 102rpx),
  linear-gradient(180deg, #FAF9F7 0%, #F2E6DF 100%);
```

### 3.2 图标优化

**现有问题**：
- 部分图标使用emoji，不够精致
- CSS图标样式不统一

**优化方案**：
1. 统一CSS图标设计语言
2. 增加微动效（hover/active状态）
3. 优化图标尺寸和间距

### 3.3 陪伴系统完善

**新增功能**：
1. **分享绑定机制**
   - 生成专属邀请码
   - 微信分享卡片
   - 扫码绑定流程

2. **权限管理**
   - 情绪数据可见范围
   - 提醒通知设置
   - 隐私保护开关

3. **互动功能**
   - 陪伴者留言板
   - 关怀提醒推送
   - 情绪波动通知

### 3.4 经期情绪监测

**新建页面：pages/period-tracker**

**核心功能**：
1. **经期记录**
   - 周期追踪日历
   - 症状记录（痛经、情绪波动）
   - 预测下次经期

2. **情绪关联分析**
   - 经期前后情绪对比
   - 情绪波动曲线图
   - 个性化建议

3. **健康提醒**
   - 经期倒计时
   - 情绪关怀提示
   - 健康小贴士
