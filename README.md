## 📖 项目背景

### 情绪经济时代的到来

在现代社会节奏加快和生存压力增加的背景下，**情绪健康问题**日益凸显。占人口比例约15%-20%的**高敏感人群（HSP）**，因其神经系统对环境刺激、情绪变化及社交互动具有更深层次的加工倾向，正承受着远超常人的心理负荷。

传统心理健康服务面临三大困境：
- **高昂成本**：真人心理咨询的边际成本和定价门槛使长期情绪陪伴成为奢侈品
- **时空限制**：服务受制于物理绑定，无法提供即时性、全天候的倾听空间
- **社会偏见**：病理化认知和标签化偏见导致强烈的病耻感与防御心理

### 认知型数字资产的价值创造

随着大语言模型技术的爆发，**AI Agent**从规则匹配式聊天机器人演进到具备长短期记忆、多模态感知和拟人化回应能力的认知智能体。基于AI的情绪陪伴服务恰好填补了高敏感人群的市场缺口：

- ✅ **低边际成本** — 规模化情感服务成为可能
- ✅ **绝对隐私保护** — 无审判的安全空间
- ✅ **去标签化** — 摆脱传统心理咨询的病理化框架
- ✅ **全天候可及** — 随时随地的情感支持

用户与AI的深度互动中沉淀的**"对话记忆"与"情感图谱"**，构成了**认知型数字资产（Cognitive-Digital Assets）**。这类资产依赖用户的情感投入和认知嵌入，具有极强的用户锁定效应和长期价值创造潜力。

> 💡 **理论基础**：本项目的价值创造机制基于北京工商大学本科毕业论文《认知型数字资产的估值问题研究——以AI心理健康平台为例》的研究成果，该研究创新性地将认知资产溢价因子整合入实物期权估值框架，为AI情绪陪伴平台的商业价值提供了理论支撑。

## ✨ 核心功能

### 🎯 情绪记录与觉察
- **12种核心情绪识别**：开心、平静、难过、疲惫、烦躁、焦虑、愤怒、感动、困惑、无聊、震惊、不知道
- **情绪颗粒度训练**：每种情绪提供8个衍生词，帮助用户精准识别情绪状态
- **身体感受记录**：关联情绪与身体反应，建立身心连接
- **快速记录模式**：30秒完成情绪打卡，无需强制AI对话

### 💬 AI情绪陪伴（小知）
- **个性化人设**：基于用户画像（性别、年龄、职业、情绪困扰类型、使用目标）动态调整对话策略
- **心理学工具箱**：整合CBT、ACT、情绪聚焦疗法、依恋理论、叙事疗法
- **自然对话风格**：像朋友一样温暖，避免套路化开头和专业术语堆砌
- **Markdown渲染**：支持粗体、斜体、表格、列表，提升对话可读性
- **对话历史管理**：消息编辑、版本历史、收藏/书签、语音输入

### 🎓 表达训练系统
**模拟对话训练**（AI驱动）
- 4个预设场景：日常沟通、表达拒绝、处理冲突、安慰他人
- 自定义场景：用户描述任意对话情境，AI自动生成NPC
- 实时教练反馈：对话过程中穿插教练点评和改进建议
- 训练评分与总结：亮点总结 + 改进建议 + 等级评定

**感官写作训练**
- 7个情绪场景（含自定义）：雨天的忧伤、收到好消息、深夜的孤独等
- 五感框架：视觉、听觉、触觉、嗅觉、味觉
- AI辅助引导：为每个场景×感官生成针对性提示语
- 词语卡片池：预设词语标签，点击即可填入写作区

### 📚 心理学知识库
- **认识情绪**：情绪颗粒度（Lisa Feldman Barrett研究）
- **理解模式**：认知扭曲（Aaron Beck的CBT方法）、依恋理论（Bowlby & Ainsworth）
- **设计原则**：完全免费、基于学术研究、通俗语言、可操作练习

### 📊 数据可视化与分析
- **情绪日历**：月度视图 + 情绪颜色标记 + 记录数量指示
- **统计面板**：周/月/全部时间范围切换 + 情绪分布横向柱状图
- **AI情绪分析**：生成情绪趋势摘要和个性化建议
- **数据导出**：CSV格式导出完整记录

### 🌸 她的时间（女性专区）
- **生理期追踪**：周期可视化、痛经程度记录（0-10级）
- **经期情绪报告**：情绪总览、分布图、关联分析、个性化建议
- **护理知识与社区**：分类标签筛选、专业知识区、社区经验分享

### 🌳 知愈之树（个人主页）
- **Canvas粒子动画**：30粒子Morandi色系动态效果
- **功能节点**：她的时间、情绪库、疗愈商店、设置、关于知愈
- **用户资料卡**：头像、昵称、座右铭

## 🚀 技术架构

### 前端技术栈
```
框架：微信小程序原生开发
样式：WXSS（Flexbox + Grid布局）
数据存储：本地Storage + 云数据库双轨
```

## 🛠️ 快速开始

### 环境要求
- 微信开发者工具 >= 1.06.0
- Node.js >= 14.0.0
- 微信小程序账号（已开通云开发）

### 安装步骤
```bash
# 1. 克隆仓库
git clone https://github.com/Lessie-wang/zhiyu-miniapp.git

# 2. 切换到v1.2.0分支
git checkout v1.2.0

# 3. 使用微信开发者工具打开项目
# 导入项目 → 选择项目目录 → 填写AppID

# 4. 配置云开发环境
# 云开发控制台 → 创建环境 → 获取环境ID
# 修改 app.js 中的 env 参数

# 5. 配置AI API
# 修改 utils/ai.js 中的 API_KEY
```
