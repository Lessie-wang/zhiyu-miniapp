# 表达训练与感官写作页面重新设计方案

## 方案概述

针对 **dialogue-training（表达训练）** 和 **sensory-writing（感官写作）** 两个页面，提供3个不同风格的重新设计方案。

---

## 方案1：卡片式沉浸体验（推荐）

### 设计理念
- **核心思想**：将训练场景/写作场景设计成"沉浸式卡片"，用户像翻阅故事书一样进入不同场景
- **视觉风格**：大卡片 + 景深层次 + 流动动画
- **交互方式**：滑动切换场景，点击进入训练

```

│  │  "朋友约你周末..."│          │

```

#### 视觉特点
- **场景卡片**：3D翻转效果，正面显示场景信息，背面显示训练目标
- **难度标识**：星级 + 颜色渐变（简单=绿色，中等=橙色，困难=红色）
- **进度可视化**：环形进度条显示各类型训练完成度
- **动画**：卡片入场动画（错开延迟）+ 悬浮呼吸动画


#### 视觉特点
- **动态背景**：每个场景有独特的动画背景（雨滴下落、星星闪烁、花瓣飘落）
- **场景氛围**：背景音效提示（可选）+ 环境光效
- **写作区域**：半透明玻璃拟态输入框，融入场景
- **引导提示**：场景相关的感官提示词（视觉、听觉、触觉、嗅觉、味觉）

## 方案2：时间轴叙事风格

### 设计理念
- **核心思想**：将训练/写作过程设计成"成长时间轴"，强调进步和积累
- **视觉风格**：垂直时间轴 + 里程碑节点 + 成就徽章
- **交互方式**：向下滚动查看历史，点击节点回顾

### 表达训练页面设计

#### 布局结构
```
┌─────────────────────────────────┐
│  [顶部统计卡片]                  │
│  你已完成 23 次训练              │
│  解锁 5 个成就徽章               │
├─────────────────────────────────┤
│         │                       │
│    ●────┤ 今天                  │
│    │    │ 日常沟通训练 ✓        │
│    │    │                       │
│    ●────┤ 昨天                  │
│    │    │ 表达拒绝训练 ✓        │
│    │    │                       │
│    ⭐───┤ 3天前                 │
│    │    │ 解锁"沟通达人"徽章    │
│    │    │                       │
│    ●────┤ 5天前                 │
│         │ 处理冲突训练 ✓        │
└─────────────────────────────────┘
```

#### 视觉特点
- **时间轴线**：渐变色线条，从上到下颜色加深（象征成长）
- **节点类型**：普通训练（圆点）、成就解锁（星星）、里程碑（奖杯）
- **卡片展开**：点击节点展开详情卡片，显示训练内容和反馈
- **成就系统**：顶部展示已解锁徽章，点击查看详情

## 方案3：游戏化关卡设计

### 设计理念
- **核心思想**：将训练/写作设计成"闯关游戏"，增加趣味性和挑战感
- **视觉风格**：关卡地图 + 解锁机制 + 奖励系统
- **交互方式**：完成前置关卡解锁后续关卡

### 表达训练页面设计

#### 布局结构
```
┌─────────────────────────────────┐
│  [关卡地图 - 曲线路径]           │
│                                 │
│         ⭐ 终极挑战（锁定）      │
│        /                        │
│       ●  困难关卡（已完成）      │
│      /                          │
│     ●  中级关卡（已完成）        │
│    /                            │
│   ●  初级关卡（已完成）          │
│  /                              │
│ 🏁 新手教程（已完成）            │
│                                 │
│  [当前关卡详情]                  │
│  关卡3：处理冲突                 │
│  奖励：+50经验 +1徽章            │
│  [开始挑战]                      │
└─────────────────────────────────┘
```

#### 视觉特点
- **关卡路径**：S形曲线路径，从下到上逐级解锁
- **关卡状态**：已完成（绿色勾）、进行中（黄色圆点）、锁定（灰色锁）
- **奖励预览**：每个关卡显示可获得的经验值和徽章
- **Boss关卡**：每5个关卡有一个特殊挑战关卡

#### 技术实现要点
```css

  background: #E0E0E0;
```

- **每日挑战**：每天推荐一个场景，完成获得额外奖励
- **成就系统**：收集所有场景的"完美写作"徽章

## 推荐方案

**推荐方案1：卡片式沉浸体验**

### 推荐理由
1. **视觉效果最佳**：大卡片设计符合当前大厂游戏级UI趋势
2. **开发成本适中**：相比方案3的游戏化系统，开发量更可控
3. **用户体验友好**：直观的卡片滑动交互，学习成本低
4. **与现有风格一致**：延续Mine页面的玻璃拟态和Morandi色系
5. **扩展性强**：未来可以轻松添加新场景卡片

### 实施建议
1. **第一阶段**：实现基础卡片布局和场景切换
2. **第二阶段**：添加3D翻转效果和动画
3. **第三阶段**：完善统计和记录功能
4. **第四阶段**：优化性能，确保60fps流畅度
