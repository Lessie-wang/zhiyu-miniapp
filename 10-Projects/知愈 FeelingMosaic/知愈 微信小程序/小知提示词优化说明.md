## ✅ 改动清单

### P0 优先级（核心功能增强）

#### 1. 增加Few-shot范例章节（第159行前）
**位置：** 在"【安全守护】"章节之前  
**内容：** 插入10个完美对话范例  
**目的：** 
- 给AI提供具体的对话模式参考
- 减少"说得很像懂，其实没懂"的情况
- 提升回复质量和人格一致性

**范例覆盖场景：**
1. 用户低能量时 - 先陪着，不追问
2. 用户自我否定时 - 立刻坚定站队
3. 用户倾诉人际冲突时 - 先站队，再了解
4. 用户连续短句时 - 陪着，不逼TA展开
5. 用户问问题时 - 先正面回答，再补充
6. 用户说模糊情绪时 - 帮TA拆解识别（教练时刻）
7. 用户说"不知道怎么说"时 - 给表达模板（教练时刻）
8. 用户说"只有你懂我"时 - 温和引导，不强化依赖（边界时刻）
9. 用户分享开心事时 - 真实兴奋回应
10. 用户情绪复杂时 - 允许模糊，不逼定义

**格式：**
```
用户："[输入]"
❌ 错误："[不好的回应]"（原因）
✅ 正确："[好的回应]"（原因）
→ 目标：[这个场景的核心原则]
```

#### 2. 增加情绪识别引导（第92行后）
**位置：** 在心理学知识引入部分之后  
**内容：** 新增"【情绪识别与表达引导】"章节  
**目的：** 
- 明确"教练"功能的具体操作方式
- 帮助AI在陪伴的同时引导用户识别和表达情绪

**具体内容：**
- 用户说模糊情绪时的拆解方式
- 用户说"不知道怎么说"时给表达模板
- 用户倾诉人际冲突后引导表达策略
- 用户表达需求困难时示范"需求语言"

#### 3. 增加表达能力档案注入（第365行后）
**位置：** 在记忆注入逻辑之后，return之前  
**内容：** 从userProfile.expressionProfile读取并注入表达能力数据  
**目的：** 
- 追踪用户的表达能力成长轨迹
- 让小知记住用户"擅长什么、卡在哪里、正在练习什么"
- 在合适时机自然体现"我记得你上次做到了"

**注入字段：**
- strengths：擅长的表达方式
- blocks：卡住的地方
- practicing：正在练习的
- milestones：成长里程碑（最近3条）

#### 5. 细化"引导"步骤（第79行后）
**位置：** 在"【最重要的原则】"章节之后  
**内容：** 新增"【引导的具体动作】"章节  
**目的：** 
- 将抽象的"引导"拆解为具体的4步操作
- 让AI知道"引导"不是空洞的概念，而是有具体方法

**4步操作：**
1. 识别情绪：帮TA把模糊的感受拆解清楚
2. 命名感受：给TA几个选项，让TA自己选
3. 示范表达：给TA具体的表达模板
4. 引导练习：邀请TA思考或模拟

#### 6. 增加高危场景应对（第140行后）
**位置：** 在自杀/自残应对流程之后  
**内容：** 增加家暴、性侵等场景的应对流程  
**目的：** 
- 覆盖更多高危场景
- 提升产品的安全性和社会责任

**新增场景：**
- 家暴、性侵等暴力伤害
- 应对流程：确认安全 → 站在TA这边 → 建议专业资源 → 持续陪伴

## 📝 使用建议

### 1. 表达能力档案的数据结构
为了让新增的表达能力档案注入生效，需要在用户画像中增加以下字段：

```javascript
userProfile.expressionProfile = {
  strengths: ['能说出"我累了"这类基础情绪', '开始能区分"生气"和"委屈"'],
  blocks: ['不知道怎么表达需求', '怕说出来会伤害对方'],
  practicing: ['用"我需要……"代替"你为什么不……"'],
  milestones: [
    {
      date: '2026-04-25',
      achievement: '第一次跟室友说了"我需要安静"'
    }
  ]
};
```

### 2. 如何记录成长里程碑
建议在以下时机自动记录：
- 用户成功表达了之前"说不出口"的话
- 用户在真实关系里应用了小知教的方法
- 用户主动分享"我今天跟XX说了……"

### 3. 如何测试优化效果
**测试场景1：模糊情绪**
- 用户输入："烦"
- 期望回复：帮TA拆解（"是被卡住的烦，还是被掏空的烦？"）

**测试场景2：不知道怎么说**
- 用户输入："我想跟我妈说我压力大，但不知道怎么开口"
- 期望回复：给表达模板（"如果是我，我会说……"）

**测试场景3：只有你懂我**
- 用户输入："感觉只有你懂我"
- 期望回复：温和引导（"可能不是只有我懂……"）
